- Endpoint: `https://drama.vixelai.com/api/mcp`

- Tool-schema SHA-256: `1729e844c7c3153ca0d84e68cb67874faf47c732573f47ac4ace473deccab402`

The MCP endpoint is the RFC 8707 OAuth resource. The plugin intentionally does
not set an `oauth_resource` override because Codex/rmcp derives the endpoint
resource during discovery.

## Canonical rules

- The authenticated Vixel Work graph is the sole production truth.
- Writes use exact `expectedRevisionId` / `expectedWriteVersion` and stable keys where required by the registered schema.
- Save the canonical Script before the initial Elements/Shots. Use the same Work in CLI, MCP and browser.
- Generation requires a fresh quote, explicit budget and stable key; recover the original Job.
- Asset review is an explicit creator decision. Timeline edits return canonical receipts.
- Export manifests describe the accepted first-route cut. Local CLI rendering is not a server Job.
- Prepared releases are not published posts. Social publishing and audience metrics remain unavailable.

## Compatibility and release

canonical plugin source. This repository is a source-free Marketplace and
installation mirror. A release is acceptable only when its provenance and
bundle hashes pass CI against this generated contract.

Production OAuth deployment and a real signed-in Codex acceptance are separate
release gates. An RC bundle does not claim that those gates have passed.
